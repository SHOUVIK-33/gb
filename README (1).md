# Gayatri — A Page from the Heart

A small, personal single-page website — a quiet expression of one-sided love.
Built with plain HTML, CSS and JavaScript in a single file, ready to publish with
GitHub Pages.

## What's inside

Everything lives in one file: **`index.html`**. It contains the HTML, the styling and the
small script, so you only have to upload this one file.

- A soft, responsive design (works on phone and desktop)
- Gentle floating-hearts animation
- Sections: a short note on the feeling, a small "about her" card, her favourite colours, and a closing wish

## Publish it with GitHub Pages

1. Create a new repository (make it **Public**).
2. Upload `index.html` (and this `README.md`) — then click **Commit changes**.
3. Go to **Settings → Pages**.
4. Under **Source**, choose **Deploy from a branch**.
5. Set **Branch** to `main` (or `master`, whichever your repo uses) and the folder to **/ (root)**.
6. Click **Save**, wait a minute, and open:
   `https://<your-username>.github.io/<repository-name>/`

## Editing the text

Open `index.html` on GitHub, click the pencil (✏️) icon, change the words, and commit.
GitHub Pages updates by itself. All the text sits inside the `<body>` — look for the
sections marked with `<!-- ===== ... ===== -->`.
